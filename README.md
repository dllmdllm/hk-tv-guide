# 今晚睇咩

香港 14 條免費電視頻道的每日節目表，支援前後日期、頻道篩選、搜尋及「直播中」進度。

## 本機使用

```bash
npm install
npm run fetch-data
npm run dev
```

## 資料來源

- 香港電台公開節目表（31–35）
- HOY 公開節目表（76–78）
- TVB / myTV SUPER 公開節目表（81–84）
- ViuTV 公開節目表（96、99）

節目如有更改，以電視台最後公布為準。程式只保存節目名稱、播放時間、簡介及官方來源連結，不保存影片內容。

## GitHub Pages

Repository 的 **Settings → Pages → Source** 選擇 **GitHub Actions**。Workflow 會每四小時更新節目資料、保存每日 JSON archive，再發布靜態網站。

## 更新及驗證

`fetch-data` 先合併及驗證全部候選 archive，再寫入資料。來源失敗或移出抓取窗口時保留已有資料；跨午夜節目會出現在每個重疊的香港日期。歷史缺漏不會推測或補造。

每個日期保存各來源／頻道的完整性及實際成功更新時間；舊版只有全次更新時間的資料會顯示狀態未確認。完整性要求全日連續覆蓋，估計結束時間及衝突不視為完整。今天超過六小時未確認更新會顯示警告；空白不代表停播。GitHub Actions 通過測試及 production build 後才保存及發布資料。

手機首次開啟預設 81 台；已選頻道會保留，切換螢幕尺寸不會覆蓋使用者選擇。有正在播放節目時自動定位到該節目；沒有時保留原位置並提示，不跳到其他時段。日期載入失敗可重試。

```bash
npm run lint
npm test
```

節目卡按完整標題及簡介的實際高度展開，至少 48px 高。所有頻道、時間標記及跳轉共用同一時間映射；來源時間互相衝突時並排保留，避免遮住節目。字型或欄寬改變後會重新量度。

揀任何一個頻道都會返回香港今日，待該台卡片高度穩定後跳到正在播放節目。跳轉以瀏覽器實際可見區域計算，長卡顯示開頭，短卡完整顯示；未有節目／資料時提示並保留位置。
